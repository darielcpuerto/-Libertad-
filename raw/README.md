# Datos Crudos (Raw Data)

Por limitaciones de tamaño (el archivo principal pesa 381 MB), los archivos CSV originales no se incluyen en este repositorio. 

Para replicar el análisis, descarga los siguientes archivos y colócalos en esta misma carpeta (`raw/`) antes de ejecutar los scripts de limpieza:

1. **`asamblea.csv`**: Votos de la Asamblea General de la ONU (1946-presente).
   * Descarga desde Harvard Dataverse (Erik Voeten): https://doi.org/10.7910/DVN/LEJUQZ
2. **`sc_votos.csv`**: Votos del Consejo de Seguridad.
   * Descarga desde UN Digital Library: https://digitallibrary.un.org
